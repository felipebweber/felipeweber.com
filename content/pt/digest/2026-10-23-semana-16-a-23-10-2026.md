> Semana de 16 a 23/10/2026. Resumo do que rolou no X sobre desenvolvimento iOS + IA.

## iPhone Duo chega às lojas e muda o "pronto para produção"

O iPhone Duo foi lançado em 23/10. Só apps compilados com o SDK do iOS 27.1 ocupam toda a tela interna e ganham o selo "Made for iPhone Duo" na App Store; builds com SDKs antigos abrem como janela centralizada com espaço vazio nas laterais. Screenshots do Duo passam a ser obrigatórios a partir de abril de 2027 para apps com SDK 27.1+, e a App Store Connect aceita envios otimizados para o Duo desde 05/10. Teve dev relatando app adaptado ao Duo com Claude Code e Codex, enviado à noite e aprovado ao meio-dia seguinte.

A Apple incluiu no Xcode uma Agent Skill oficial chamada app-resizability, que ajuda agentes como Codex e Claude Code a identificar e migrar APIs legadas para layouts redimensionáveis. ## Xcode 27.2: projeto em JSON pensado para agentes

O Xcode 27.2 RC (27B48) saiu em 19/10 e a versão final em 23/10. A grande mudança: novos projetos usam um arquivo JSON (project.xcproj) no lugar do velho project.pbxproj. As notas da Apple dizem que o formato é menor, open source, gera menos conflitos de merge e é "mais fácil para agentes de código editarem"; a Apple também abriu um pacote Swift para serializar o formato. O Xcode 27 abre os dois formatos. Outras novidades: o Device Hub agora simula pressão de memória, animações lentas, shake e queda, e desde o beta 3 há uma skill xctrace para análise do Instruments, exportável com `xcrun agent skills export`.

## UIScene obrigatório no iOS 27

Alerta prático: apps UIKit compilados com o Xcode 27 sem o ciclo de vida de UIScene não abrem no iOS 27. Afeta React Native, Expo e .NET MAUI; no Expo SDK 57 a saída é `enableSceneSupport` em expo-build-properties. O Expo SDK 58 chegou com iOS 27, RN 0.88 e expo-app-intents para Siri/Apple Intelligence.
